# ClearMind

Personal mind organizer — capture thoughts into an inbox, then organize by category and priority in List or Board views. Data stays in your browser (`localStorage`).

## Run

```bash
npm install
npm run dev
```

Open the URL Vite prints (default `http://localhost:5173`).

## Features

- **Inbox** — fast capture, then assign category/priority and move to Todo
- **List** — filter by status, category, and priority
- **Board** — Todo / Doing / Done columns with drag-and-drop
- **Categories** — create and color-code your own
